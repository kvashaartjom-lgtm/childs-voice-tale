# Child's Voice Tale — Project Definition

## Product
Global personalized publishing platform using AI to create illustrated books and produce a physical book for delivery.

## MVP
- Launch: Netherlands / EU
- Website first
- iOS and Android use the same backend
- Physical personalized book is the primary product
- Digital copy is included
- Printing/fulfillment is outsourced to B2B providers

## Core principle
Build the MVP as a production foundation. Avoid hard-coding country, currency, tax, printer, shipping, payment provider, or language assumptions into the UI.
